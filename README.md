# Rehablito Courses

Official online learning and pediatric rehabilitation platform for **Rehablito Academy** (Speech Therapy & Autism Center).

## Features
- Comprehensive course catalogue & video player for child therapy, ASD, and special education
- Interactive student learning dashboard with real-time watch progress and streak tracking
- Automatic certificate issuance and credential verification (`/verify`)
- Full administrator suite with intelligence hub, revenue analytics, and student management
- Razorpay integrated payment checkout

## Getting Started
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
